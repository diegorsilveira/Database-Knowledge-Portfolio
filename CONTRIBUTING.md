# Como contribuir

1. Mantenha cada script no diretório do SGBD correspondente.
2. Utilize nomes de arquivos descritivos em letras minúsculas e hífens.
3. Inclua cabeçalho com SGBD, categoria, objetivo, impacto e pré-requisitos.
4. Não publique nomes de servidores, IPs, usuários reais, caminhos internos,
   dados de clientes ou informações corporativas.
5. Informe a versão do SGBD quando houver dependência de versão.
6. Identifique claramente scripts que alteram dados, estruturas ou permissões.

# Oracle Database

Scripts para administração básica, consulta de tablespaces, quotas e permissões.

## Conteúdo

| Diretório | Conteúdo |
|---|---|
| `01-Administracao` | Inventário de tablespaces e quotas |
| `02-Seguranca` | Concessão de quota em tablespace |

Algumas views DBA_ exigem privilégios de catálogo. Quando não houver acesso,
avalie as views USER_ ou ALL_ equivalentes.

## Novos conteúdos deste lote

- Inventário de objetos inválidos e tamanho dos datafiles.
- Auditoria de roles, privilégios de sistema e privilégios sobre objetos.
- Status de contas e monitoramento de sessões.
- Geração de comandos para encerramento de sessões e recompilação.

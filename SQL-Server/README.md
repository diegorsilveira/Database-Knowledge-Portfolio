# Microsoft SQL Server

Scripts para administração, segurança, monitoramento, performance e troubleshooting.

## Conteúdo

| Diretório | Conteúdo |
|---|---|
| `01-Administracao` | Backup, histórico e arquivos físicos |
| `02-Seguranca` | Usuários, roles e permissões |
| `03-Performance` | Índices e utilização |
| `04-Troubleshooting` | Transações, transaction log e replicação |

Os scripts são exemplos genéricos. Ajuste os parâmetros para o ambiente antes de executar.

## Novos conteúdos deste lote

- Tamanho alocado por banco e estatísticas de I/O por arquivo.
- Inventário de logins e revisão de permissões de roles.
- Estimativa de última atividade registrada em DMVs.
- Progresso de backup/restore, sessões, requisições e consumo de TempDB.

# IBM Db2 LUW

Scripts para administração, monitoramento, manutenção e troubleshooting do Db2 LUW.

## Conteúdo

| Diretório | Conteúdo |
|---|---|
| `01-Administracao` | Inventário de MQTs, refresh e RUNSTATS |
| `02-Monitoramento` | Conexões, atividades, locks e armazenamento |
| `03-Performance` | Estatísticas e consultas de diagnóstico |
| `04-Troubleshooting` | Comandos db2pd |

Verifique versão, autoridade e estado dos objetos antes de executar comandos administrativos.
